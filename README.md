# Sistema de Contingência de Atendimento

Protótipo desenvolvido para atendimento de exames em modo offline.

O sistema permite:

- Importar planilhas de agendamento
- Gerar fichas de atendimento em PDF
- Gerar etiquetas de identificação
- Registrar atendimentos manuais
- Exportar planilha de atendimentos

Tecnologias utilizadas:

- HTML
- CSS
- JavaScript
- SheetJS (leitura de Excel)
- jsPDF (geração de PDF)
